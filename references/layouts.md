# 版式模板库

10 种通用版式。根据内容类型选择，可任意组合。每个版式给出坐标骨架，填内容即可。

所有版式基于 960×540 画布，边距 60px。

---

## 版式 1：封面

**适用**：每页 deck 的第一页。
**布局**：左文右装饰。

```
背景：linear-gradient(110deg, 深蓝渐变)
左侧文字区 x=60：
  - 章节标签（顶部 y=40）：英文小字
  - 主标题第一行 y=180：白色 60px 粗体
  - 主标题第二行 y=260：绿色 60px 粗体
  - 副标题 y=360：白色 18px
  - 引导小字 y=392：灰色 13px
  - 署名/日期 y=480：灰色 13px
右侧装饰区 x=620 起：
  - 大椭圆（半透明绿 alpha 0.10）
  - 小椭圆（alpha 0.16）
  - 3 个胶囊标签（绿/白/黄，y=410）
  - 小圆点点缀
```

## 版式 2：数据概览（左色块+横排指标）

**适用**：开头概览、年度总结、核心指标展示。
**布局**：左上绿色块标题 + 右侧 3–5 个大数字横排。

```
左上绿色块 (0,0,340,290)：
  - 章节号 y=50
  - 大标题 y=90：深青字 40px
  - 英文副标题 y=160
  - 简短描述 y=210
右侧文字区 x=380：
  - 引导语 y=50：白色 15px，两行
  - 数据横排 y=180：每个宽 100–120px，间距 20px
    - 大数字 40px Montserrat（绿/白/黄交替）
    - 说明文字 y=240：灰色 12px
  - 分隔线 y=340
  - 关键词标签 y=410：绿色 14px
```

**指标数量**：3–5 个为宜，超过 5 个换行或拆页。

## 版式 3：柱状图/季度成果

**适用**：季度演进、年度成果、数据对比。
**布局**：左侧标题描述 + 右侧 4 根柱子 + 底部绿色数据条。

```
左侧标题区 x=60：
  - 章节号 y=60
  - 大标题 y=95：白色 38px
  - 描述文字 y=170：灰色 13px，宽 290
柱状图区 x=420–900：
  - 4 根柱子，宽 60px，间距均匀
  - 柱子高度按数据比例（最高 160px，最低 100px）
  - 颜色：绿/白/黄/深绿 交替
  - 柱顶放 Q1/Q2/Q3/Q4 标签（y=柱顶-32）
  - 柱下放季度名称（y=350）
底部绿色数据条 (0,430,960,110)：
  - 4 个数据横排：大数字 32px 深青 + 说明 12px
```

## 版式 4：左图右文（挑战/问题）

**适用**：三个并列挑战、问题、要点清单。
**布局**：左侧椭圆视觉 + 右侧 01/02/03 列表。

```
左侧视觉区 (0,80,380,420)：
  - 大椭圆渐变背景
  - 3 个三角/几何图形模拟山峦（绿/白/黄半透明）
右侧文字区 x=440：
  - 章节号 y=50
  - 大标题 y=85：白色 36px
  - 引导语 y=150：灰色 13px
  - 三个条目，每个间隔 90px（y=220, 310, 400）：
    - 左侧编号 01/02/03：绿/绿/黄 22px Montserrat
    - 短横线装饰（编号后）
    - 条目标题：白色 15px 粗体
    - 条目描述：灰色 12px
```

## 版式 5：卡片拼贴（反思/痛点）

**适用**：3 个反思、痛点、不足。
**布局**：左侧标题 + 右侧 3 张白色卡片错落排列。

```
左侧标题区 x=60：
  - 章节号 y=60
  - 大标题 y=95：白色 36px
  - 引导语 y=165
  - 页码/方向 y=420：大数字 32px + 说明
右侧 3 张白色卡片（round-rect，白色 0.96）：
  - 卡片1 (400,70,240,180)
  - 卡片2 (660,130,240,180)
  - 卡片3 (480,330,420,160) — 第三张宽一点
每张卡片内：
  - 编号 01/02/03：彩色 24px（绿/黄/红）
  - 卡片标题：深青 15px 粗体
  - 描述：灰色 11px
  - 改善方向：绿色 11px
```

## 版式 6：三栏方法论

**适用**：方法论、框架、理念+执行+数据。
**布局**：左标题+白色 Idea 卡 / 中 Execution / 右绿色数据块。

```
左侧 (60,50,280宽)：
  - 章节号 + 大标题 + 引导语
  - 白色 Idea 卡片 (60,220,280,270)：
    - 三个子项，每个带彩色小圆点
    - 子项英文小标题（绿/黄/红）
    - 中文描述
中间 (380,80,280宽)：
  - Execution 标题（绿 26px）
  - 流程步骤两行（白色 14px，箭头绿色）
  - Killer Feature 区块：黄色小标题 + 白色大标题 + 灰色描述
右侧绿色块 (700,0,260,540)：
  - 3 组数据竖排：
    - 大数字 48px 深青
    - 说明 12px
```

## 版式 7：时间线/路线图

**适用**：季度计划、年度路线图、阶段推进。
**布局**：左侧标题 + 横向时间线 + 4 个节点 + 底部目标。

```
左侧标题区 x=60：
  - 章节号 + 大标题 + 引导语
时间线主轴 y=260：从 x=120 到 x=900，白色 alpha 0.25
4 个节点，x 位置 140/340/540/740：
  - 节点圆点（直径 16，颜色：灰/绿/黄/白）
  - 上方标签 Q1/Q2/Q3/Q4（y=215）
  - 下方胶囊标签（y=285，宽 120，颜色对应）
  - 标签下方描述（y=328，宽 150）
底部 (60,425)：
  - 2027 TARGET 绿色小标题
  - 目标三个指标横排（白色 14px，数值绿色粗体）
```

**适用**：价值定位、角色描述、三个方向。
**布局**：左上绿色大圆角块 + 下方三列。

```
左上绿色块 (0,0,440,280)：

  - 每列：彩色小圆点 + 白色标题 16px

底部分隔线 + 核心价值行（y=490）：
  - 左侧"我的核心价值"
  - 右侧英文关键词（绿色 14px）
```

## 版式 9：团队/角色致谢

**适用**：团队介绍、协作方、多角色感谢。
**布局**：左侧标题 + 5 个圆形角色卡片分两行。

```
左侧标题区 x=60：
  - 章节号 + 大标题 + 引导语
  - 底部金句（绿色 14px）
5 个圆形（直径 80，fillColor 彩色）：
  - 第一行 3 个：x=400/560/720，y=90
  - 第二行 2 个：x=480/680，y=300
  - 圆内放角色首字（白色/深青 24px）
每个圆下方：
  - 团队名（白色 15px 粗体，居中）
  - 一句话描述（灰色 11px，居中，宽 120–140）
```

**颜色分配**：产品=绿、研发=白、测试=黄、业务=红、管理=灰。

## 版式组合建议

**标准 10 页汇报**：
1. 封面 → 版式 1
2. 年度概览 → 版式 2
3. 项目成果 → 版式 3
4. 关键挑战 → 版式 4
5. 问题不足 → 版式 5
6. 方法论 → 版式 6
7. 行动计划 → 版式 7
8. 价值定位 → 版式 8
9. 协同感谢 → 版式 9
10. 结束页 → 版式 10

**短版 5 页**：封面 → 数据概览 → 时间线 → 三栏 → 结束页

**长版 15 页**：封面 → 目录（可复用版式 2）→ 章节页（用版式 4 变体）→ 3–5 个内容页（版式 3/5/6 交替）→ 路线图 → 团队 → 结束页

**原则**：相邻两页不要用同一版式，保持视觉节奏变化。
