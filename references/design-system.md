# 设计系统规范

所有颜色、字体、间距必须严格遵循本规范，不要自创。

## 配色

| 角色 | 色值 | 用途 |
|---|---|---|
| 主背景 | `rgb(12,24,42)` | 页面底色，深藏青 |
| 背景渐变 | `linear-gradient(110deg,rgba(11,22,40,1) 0%,rgba(14,30,52,1) 55%,rgba(18,52,60,1) 100%)` | 封面/结束页背景 |
| 主色绿 | `rgba(61,214,140,1)` | 标题强调、色块、标签、数据 |
| 深绿 | `rgba(46,180,120,1)` | 次级绿、柱状图交替色 |
| 点缀黄 | `rgba(245,197,66,1)` | 关键强调、第三色、高亮 |
| 白色 | `rgba(255,255,255,1)` | 主标题、反白文字 |
| 次白 | `rgba(255,255,255,0.9)` | 正文 |
| 灰文字 | `rgba(160,172,188,1)` | 说明文字、副标题 |
| 深灰块 | `rgba(120,135,155,1)` | 中性色块、Q1标签 |
| 红色点缀 | `rgba(230,120,120,1)` | 第三列/卡片编号强调 |
| 白色卡片底 | `rgba(255,255,255,0.96)` | 内容卡片背景 |
| 浅白装饰 | `rgba(255,255,255,0.18)` / `0.14` / `0.10` | 半透明装饰椭圆 |

**配色原则**：
- 一页最多用 3 种强调色（绿、黄、红/灰），不要把所有颜色都堆上
- 主色绿占主导（70%），黄点缀（20%），红/灰中性（10%）
- 文字在深色底上用白/浅灰，在白色卡片上用深青 `rgba(12,24,42,1)`

## 字体

| 用途 | 字体 | 字号 |
|---|---|---|
| 大标题（封面） | 思源黑体 + Montserrat | 40–72px，粗体 |
| 页面标题 | 思源黑体 | 32–40px，粗体 |
| 小标题/栏目标题 | 思源黑体 | 16–22px，粗体 |
| 正文 | 思源黑体 | 13–16px |
| 说明/注释 | 思源黑体 | 11–12px |
| 大数字指标 | Montserrat | 32–48px，粗体 |
| 英文小标题/章节号 | Montserrat | 11–13px，大写，letterSpacing=2 |

**注意**：
- 中英文混排时，中文用思源黑体，英文/数字用 Montserrat
- 数字后接中文单位（如"8个"），单位用 `<span fontFamily="思源黑体">` 单独指定，否则 Montserrat 不渲染中文
- 标题必须 `wrap="false"`，并把 width 设够

## 间距与布局

- 画布 960×540
- 左右边距：60px
- 顶部边距：50–60px
- 元素间距：20–40px
- 卡片圆角：`presetHandlers="16"`（卡片）或 `20`（胶囊标签）
- 章节号格式：`01 / SECTION NAME`，绿色 12px Montserrat 大写

## 装饰元素

- 半透明椭圆：`type="ellipse"`，绿色 alpha 0.10–0.16，放在右侧或角落
- 小圆点：直径 12–14px，用绿/黄/白三色点缀
- 胶囊标签：`round-rect` 高 32–40px，圆角等于高度一半
- 分隔线：白色 alpha 0.15–0.25，1px
- 不要用 emoji，不要用复杂插图，用几何形状保持风格统一

## 文字层级

每页严格按这个层级：
1. 章节号（最小、绿、大写英文）
2. 页面大标题（最大、白/绿、粗体）
3. 引导语/副标题（次小、浅灰）
4. 正文内容（中、白）
5. 注释/数据说明（小、灰）
