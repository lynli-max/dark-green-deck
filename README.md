dark-green-deck

深色商务绿风格的飞书幻灯片制作技能。

1 特点

- 深藏青底 + 亮绿主色 + 明黄点缀的现代科技风
- 内置 10 种通用版式（封面/数据概览/柱状图/左图右文/卡片拼贴/三栏/时间线/价值块/团队页/结束页）
- 支持任意页数，根据内容自动选择版式组合
- 统一视觉规范，保证跨页风格一致

2 安装方法

直接对 AI 说：

帮我安装这个 skill：https://github.com/lynali-max/dark-green-deck

AI 会自动把这个 skill 下载到本地技能目录。

3 使用方法

安装完成后，直接说：

帮我做个深色商务风的工作汇报 PPT，内容如下：xxx

AI 会自动识别并使用这个 skill，按统一的设计规范制作。
